# 星火西游 · iPhone 横版 2D App 版

这是一个可以直接放到 GitHub Pages、用 iPhone Safari 游玩的网页版 App。

## iPhone 使用
1. 把 `index.html`、`manifest.json`、`sw.js` 上传到 GitHub 仓库根目录。
2. GitHub Pages 选择 `main` / `/(root)`。
3. iPhone Safari 打开你的 Pages 地址。
4. 点「分享」→「添加到主屏幕」，就可以像 App 一样从桌面进入。
5. 横屏玩。

## 操作
- 地图：点击位置移动，点击古道区域进入战斗。
- 战斗：点击「攻击 / 法术 / 道具 / 防御 / 自动」。
- 键盘也支持 1~5、方向键，方便电脑测试。
- 游戏会尝试自动保存本地进度。

## 说明
这是原创游戏实现，采用经典老式横版中国神话 MMORPG 的结构与时代感，不直接复制商业游戏的角色、原画、地图、UI 或素材。
